Budget Tracker v4 - Editable Transactions

New feature: each transaction now has an Edit button. Tap Edit to load the amount, category, description, and date back into the entry form. Make your changes and tap Update expense. Cancel edit returns the form to normal without changing the transaction.

Carryover, editable monthly budget, and existing stored transactions remain compatible with the previous version.

To update GitHub Pages, replace the files in the repository root with these files. After Pages redeploys, refresh the site or fully close and reopen the Home Screen app.
